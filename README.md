# «Нұрайша» бөбекжай-балабақшасы

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run typecheck
```

Деплой на Vercel: импортировать репозиторий, настройки по умолчанию. Желательно задать
`NEXT_PUBLIC_SITE_URL` (например `https://nuraisha.kz`) — используется для canonical, Open Graph и sitemap.

## Что настраивается

**Контакты — `lib/site.ts`**
- `phone`: номер телефона (`"+77001234567"`). Когда он указан, в контактах появляется кнопка звонка.
- `whatsapp`: номер WhatsApp. Когда он указан, вместо надписи «скоро появится» показывается кнопка WhatsApp.
- `twoGisUrl`: проверенная ссылка на карточку объекта в 2GIS. Когда она указана, появляется кнопка «2GIS-те ашу».
- `twoGisEmbedUrl`: ссылка для встраивания карты 2GIS. Когда она указана, заглушка карты заменяется на iframe.

**Фотографии — `public/images/`**
- Поддерживаются файлы `main-page`, `main-page2`, `image1`, `image2`, … в форматах `.jpg`, `.jpeg`, `.png`, `.webp` и `.avif`.
- `main-page` и `main-page2` выводятся на главном экране, а все найденные файлы попадают в галерею.
- Список файлов читается во время сборки, поэтому после добавления фото сайт нужно пересобрать (на Vercel достаточно сделать push).
- Пока фото нет, вместо них показываются декоративные заглушки.

**Тексты KZ / RU — `lib/i18n.ts`**: русский словарь проверяется по типу казахского, поэтому пропущенная строка вызовет ошибку TypeScript.

## Структура

- `components/desktop/`: секции для экранов от 1024px.
- `components/mobile/`: отдельные мобильные секции.
- `components/shared/`: общие элементы (язык, декор, волны, лайтбокс, карта, футер, данные карточек).
